GETTING STARTED / SMALL FIRST

最初の公開までを、5つの確認点に分ける。

大きな自動化から始めません。まずは一つのページまたは一つの記事を、生成・確認・公開後確認まで通します。

WHAT TO PREPARE

道具は役割で捉える。

PC

制作と確認の場所

ブラウザとエディタで、成果物とプレビューを見ます。

CODEX / CLAUDE CODE

要件整理と実装支援

目的の言語化、設計、コードのレビューを支援します。

OLLAMA

ローカルの候補生成

文章、構造、コードの候補を限定した工程で扱います。

LARAVEL

プレビューと公開面

ページ・記事を表示し、確認できる形にします。

SQLITE

ローカル作業の記録

作業状態や承認状態を、公開面から分けて扱います。

COMFYUI / OPTIONAL

画像の拡張

画像生成は任意です。文字・ロゴの精度は目視で確認します。

THE FIRST FIVE

01

公開目的を一文にする

誰に、何を伝え、公開後に何をしてほしいかを決めます。

02

小さな成果物を一つ選ぶ

LPの1セクション、記事1本、更新1件など、確認可能な範囲から始めます。

03

生成と編集を分ける

AIの案をそのまま公開せず、事実・語調・デザインを人が見直します。

04

公開前の確認点を通す

見出し、リンク、画像、表記、表示幅を確認します。

05

公開後のURLを確認する

実際の公開面で表示を確認し、次の改善に残します。

最初から無人運用を目指さない。

目的・事実・広告・デザイン・公開判断は人に残し、反復しやすい作業だけを工程化します。効果やコスト削減は、案件ごとに記録して判断してください。
