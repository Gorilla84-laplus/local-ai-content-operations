ARCHITECTURE / 01

AIを一つの担当者にしない。

会話型エージェントの判断力を中心に置きながら、繰り返しの実行をローカルへ寄せることで、公開前後の確認を残す構成です。

THE DIFFERENCE

Codex / Claude Code単体で終わらせず、制作を次回も再実行できる工程にする。

AGENT ONLY

会話を起点に、探索と制作を進める

要件整理、設計、実装、都度レビューに強い。一方で、承認状態・本番反映・広告・投稿確認の手順は会話や担当者の記憶に埋もれやすい。

WITH OPERATIONS

判断はエージェント、反復は仕組みに置く

生成、検査、DB同期、公開確認を役割別に分離。会話の文脈を失っても、次に何を実行し確認するかを追える。

ROLE BOUNDARIES

判断・生成・表示・状態を分ける。

01

Codex / Claude Code

要件整理、設計判断、例外対応、最終レビューを担う。

02

Ollama / local LLM

文章・構造・コードの候補を、用途を絞って生成する。

03

Python / SQLite

検査、広告承認状態、同期対象、実行ログを扱う。

04

Laravel / MySQL / Pages

表示、プレビュー、本番反映、静的公開をそれぞれ担う。

BOUNDARY

ローカル保存と公開判断を分ける。

生成物はまずローカルへ

記事や候補は直ちに公開せず、ローカルDB・下書き・検査結果に留める。

同期は別工程

本番DB反映は明示的な操作として分け、公開先を誤って上書きしない。

人の承認を残す

事実性、広告、デザイン、投稿・公開の判断を自動化の外に残す。
